# Immature reticulocyte fraction (IRF) (`immature-reticulocyte-fraction`)

Percentage of reticulocytes that are the most recently released, RNA-rich (immature) forms, measured on automated analysers. Higher values indicate faster marrow recovery or increased erythropoietic demand; low values suggest reduced marrow output.
