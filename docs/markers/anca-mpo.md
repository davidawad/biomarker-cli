# ANCA, Anti-Myeloperoxidase (MPO) Antibody (`anca-mpo`)

IgG autoantibody against myeloperoxidase (MPO-ANCA), measured by immunoassay. Tracked for diagnosis and relapse monitoring in ANCA-associated vasculitis (microscopic polyangiitis, EGPA, GPA). Expected result: negative (below the assay positivity threshold).
