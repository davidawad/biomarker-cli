# Antinuclear Antibody Titer (HEp-2 IFA) (`ana-titer`)

Antinuclear antibodies measured by indirect immunofluorescence on HEp-2 cells, reported as the reciprocal of the highest positive serum dilution (1:80 = 80). Low titres are common in healthy people, so the titre and the staining pattern both matter.
