# CD8 T Cells (Absolute) (`cd8-absolute`)

Absolute count of CD8-positive (cytotoxic) T lymphocytes per microlitre of blood, measured by flow cytometry. Used in immune deficiency work-up, in HIV monitoring alongside the CD4 count, and in lymphocyte subset panels. Expected result in healthy adults: within the reference interval.
