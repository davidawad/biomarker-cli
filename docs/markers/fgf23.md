# Fibroblast Growth Factor 23 (Intact) (`fgf23`)

Intact fibroblast growth factor 23 (FGF23), a bone-derived phosphaturic hormone essential for phosphate homeostasis. Measured to evaluate FGF23-related disorders such as hypophosphatemic rickets and tumor-induced osteomalacia, where elevated levels are found. Reference intervals are assay-specific; the ranges below use the LIAISON XL chemiluminescent immunoassay. Expected result: within the healthy reference interval for the assay and age.
