# CGM time below range (<54 mg/dL) (`cgm-time-below-54`)

Percentage of CGM glucose readings (or minutes per day) below 54 mg/dL (3.0 mmol/L), the level-2 hypoglycemia threshold. Maximum targets from the International Consensus on Time in Range.
