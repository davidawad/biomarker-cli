# 1,5-Anhydroglucitol (GlycoMark) (`1-5-anhydroglucitol`)

1,5-Anhydroglucitol reflects glucose excursions over about 1-2 weeks; it falls when blood glucose exceeds the renal threshold. Low values indicate short-term hyperglycaemia.
