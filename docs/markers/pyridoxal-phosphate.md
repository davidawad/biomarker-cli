# Vitamin B6 (pyridoxal 5'-phosphate) (`pyridoxal-phosphate`)

Pyridoxal 5'-phosphate (PLP), the active form of vitamin B6, measured in serum or plasma. Low values indicate functional vitamin B6 deficiency. Inflammation also lowers PLP independently of intake.
