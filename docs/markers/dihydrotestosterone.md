# Dihydrotestosterone (`dihydrotestosterone`)

Potent androgen made from testosterone by 5-alpha-reductase in target tissues such as skin, prostate and hair follicles. Measured by LC-MS/MS; immunoassays overestimate it because of cross-reactivity, so do not compare LC-MS/MS values with older immunoassay ranges.
