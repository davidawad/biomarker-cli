# Phenylalanine (`phenylalanine`)

Plasma concentration of the essential amino acid phenylalanine. In phenylketonuria (PKU) it accumulates because phenylalanine hydroxylase is deficient, so treatment targets are set as ranges; persistently high values signal poor metabolic control.
