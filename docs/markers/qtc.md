# QTc Interval (`qtc`)

Heart-rate-corrected QT interval from a 12-lead ECG. Used to screen for QT prolongation, which raises risk of torsades de pointes with some drugs and electrolyte disturbances. Ranges are age- and sex-specific upper limits; values above the limit indicate prolonged QTc.
