# Waist-to-Height Ratio (`waist-to-height-ratio`)

Waist circumference divided by height, both in the same unit. It is a simple index of central adiposity and cardiometabolic risk that does not need sex- or ethnicity-specific cut-offs. A value of 0.5 is the commonly used boundary.
