# F2-Isoprostanes, Urine (`urine-f2-isoprostanes`)

Urinary F2-isoprostanes, measured as 8-iso-prostaglandin F2alpha and normalised to creatinine, a non-invasive marker of lipid peroxidation (oxidative stress). Expected result: below the upper reference limit in the range below. The only interval found is for children aged 2 months to 18 years; no adult interval was verified.
