# Hepatitis C Antibody (`hcv-ab`)

Antibody to hepatitis C virus in serum or plasma, reported as reactive or non-reactive, and as a signal-to-cutoff index by some assays. A reactive result shows exposure to hepatitis C virus; it does not distinguish current from resolved infection, which requires HCV RNA testing. Expected result: non-reactive (negative).
