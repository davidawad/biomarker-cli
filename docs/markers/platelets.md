# Platelets (`platelets`)

Number of circulating platelets, needed for primary haemostasis. Low values (thrombocytopenia) raise bleeding risk and have many causes including marrow failure, drugs, consumption and immune destruction; high values (thrombocytosis) occur with inflammation, iron deficiency, infection or myeloproliferative neoplasms.
