# Cortisol (PM) (`cortisol-pm`)

Serum cortisol collected in the evening (6-8 PM), measured by LC-MS/MS. Cortisol falls through the day, so evening samples have their own reference interval and collection time must be standardized. Expected result in healthy adults: within the reference interval.
