# Urine Bacteria (microscopy) (`urine-bacteria`)

Bacteria counted in unspun urine sediment, reported per microlitre by automated sediment analysers (or per high-power field by manual microscopy). Tracked as a marker of bacteriuria and of urine contamination. Expected result: low or absent bacteria in a clean-catch specimen; the only verified numeric interval found is the pregnancy interval from an automated analyser.
