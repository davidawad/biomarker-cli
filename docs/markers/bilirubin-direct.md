# Bilirubin, Direct (Conjugated) (`bilirubin-direct`)

Conjugated (direct) serum bilirubin. Used with total bilirubin to separate conjugated from unconjugated hyperbilirubinaemia; elevated direct bilirubin in infancy warrants cholestasis evaluation.
