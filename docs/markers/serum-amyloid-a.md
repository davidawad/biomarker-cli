# Serum Amyloid A (`serum-amyloid-a`)

Acute-phase inflammation marker, used to track inflammation-mediated disease. Expected result for a healthy adult: at or below the upper reference limit of 11.0 mg/L (one Chinese reference-interval study, ages 20 to 79).
