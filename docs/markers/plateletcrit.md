# Plateletcrit (`plateletcrit`)

Plateletcrit (PCT) is the total volume of platelets in blood as a percentage of whole-blood volume, calculated by automated hematology analysers from platelet count and mean platelet volume. It is tracked as a platelet-mass index alongside platelet count and MPV. Expected result in healthy people: within the analyser-specific reference interval. Values depend on the analyser model, so intervals are not interchangeable between platforms.
