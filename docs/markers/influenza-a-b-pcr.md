# Influenza A and B RNA (PCR) (`influenza-a-b-pcr`)

Molecular (RT-PCR) test on a respiratory swab that detects influenza A and influenza B viral RNA, reported separately for each type as detected or not detected. It is used to diagnose acute influenza and guide antiviral treatment. Expected result: not detected (negative).
