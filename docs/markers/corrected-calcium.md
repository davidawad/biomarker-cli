# Albumin-Corrected Calcium (`corrected-calcium`)

Total serum calcium adjusted for serum albumin with a correction formula. Correction formulas are less accurate than ionized calcium, particularly in hypoalbuminaemia and hypercalcaemia, so ionized calcium is the reference measure where available.
