# Prealbumin (Transthyretin) (`prealbumin`)

Prealbumin, also called transthyretin, a serum transport protein measured to assess nutritional status. In systemic AL amyloidosis, serum prealbumin was an independent predictor of survival in one cohort. Expected result in a healthy adult: a value within the laboratory's reference interval; no numeric healthy-population reference interval was verified for this marker.
