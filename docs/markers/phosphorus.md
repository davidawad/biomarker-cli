# Phosphorus (Phosphate), Inorganic (`phosphorus`)

Serum inorganic phosphate, which falls steadily through childhood and is regulated with calcium and PTH. Reference values are much higher in infants than in adults, and phosphate is a KDIGO CKD-MBD target.
