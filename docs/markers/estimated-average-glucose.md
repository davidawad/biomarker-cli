# Estimated Average Glucose (eAG) (`estimated-average-glucose`)

Estimated average glucose computed from HbA1c with the linear equation eAG (mg/dL) = 28.7 x HbA1c (%) - 46.7 (PMID 18540046, Diabetes Care 2008, 'Translating the A1C assay into estimated average glucose values'). Expresses HbA1c in glucose units for comparison with self-monitoring. Expected result: a value that tracks HbA1c; interpret against HbA1c thresholds.
