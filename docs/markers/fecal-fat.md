# Fecal Fat (`fecal-fat`)

Quantity of fat excreted in stool over a collection period, the classic test for fat malabsorption (steatorrhea). Measured on a standardized fat-containing diet. Elevated values point to maldigestion or malabsorption, for example exocrine pancreatic insufficiency.
