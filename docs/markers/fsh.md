# Follicle Stimulating Hormone (`fsh`)

Pituitary gonadotropin that drives ovarian follicle growth in women and spermatogenesis in men. Rises as ovarian reserve falls and after menopause, so reference values depend strongly on sex, cycle phase and menopausal status.
