# Glucose (`glucose`)

Plasma glucose, usually fasting, used to screen for and diagnose prediabetes, diabetes and gestational diabetes, and to detect hypoglycaemia. Thresholds differ between ADA, WHO, IADPSG and NICE, so the source and population matter.
