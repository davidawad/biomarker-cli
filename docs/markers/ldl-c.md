# LDL Cholesterol (`ldl-c`)

Cholesterol in low-density lipoprotein particles, the primary lipid target of therapy. Adult ATP III categories and LDL-lowering goals, 2018 AHA/ACC severe-hypercholesterolemia threshold, 2019 ESC/EAS risk-based targets, NICE secondary-prevention target, pediatric NHLBI cut-points, non-fasting flags and pregnancy reference intervals.
