# Iodine, Urine (median, population) (`urine-iodine`)

Median urinary iodine concentration in a population sample, the WHO/UNICEF/ICCIDD indicator of population iodine intake. These criteria apply to population medians, not to an individual's urinary iodine, which varies day to day.
