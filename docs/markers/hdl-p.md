# HDL Particle Number (`hdl-p`)

Total HDL particle concentration (HDL-P) measured by NMR spectroscopy, reported in umol/L. Tracked because NMR-measured HDL-P has been reported as more strongly associated with coronary artery disease and incident cardiovascular events than HDL cholesterol. Expected result: within the laboratory reference interval.
