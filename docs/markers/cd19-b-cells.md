# CD19 B Cells (Absolute) (`cd19-b-cells`)

Absolute count of CD19-positive B lymphocytes per microlitre of blood, measured by flow cytometry. Used in immune deficiency work-up (low B-cell counts) and to monitor B-cell-directed therapy. Expected result in healthy adults: within the reference interval.
