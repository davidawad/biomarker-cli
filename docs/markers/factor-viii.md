# Factor VIII activity (`factor-viii`)

Functional activity of coagulation factor VIII, measured by a one-stage clotting or chromogenic assay. Low levels define haemophilia A, with severity set by the activity level; a level below the reference range is consistent with haemophilia A or von Willebrand disease.
