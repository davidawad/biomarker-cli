# Neisseria gonorrhoeae NAAT (`gonorrhea-naat`)

Nucleic acid amplification test that detects Neisseria gonorrhoeae DNA (or RNA) in urine, urethral, vaginal, cervical, rectal or pharyngeal swab specimens. Used to diagnose gonorrhea and to screen people at risk, including for chlamydia-co-testing panels. Expected result: not detected (negative).
