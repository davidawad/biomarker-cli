# Unsaturated iron-binding capacity (`uibc`)

Part of the transferrin iron-binding capacity still free to bind iron, calculated as TIBC minus serum iron. It moves in the same direction as TIBC and inversely with transferrin saturation; it is an adjunct to the iron panel rather than a stand-alone diagnostic test.
