# Ammonia (`ammonia`)

Plasma ammonia, measured when hyperammonaemia is suspected (for example in liver failure, urea cycle disorders or other inborn errors of metabolism). Samples need prompt processing because ammonia rises in vitro. Expected result in newborns under one week: at or below the proposed reference limit of 82 umol/L.
