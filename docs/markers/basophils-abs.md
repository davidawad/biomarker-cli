# Absolute basophil count (`basophils-abs`)

Absolute count of circulating basophils, the least common white cell, involved in allergic and inflammatory responses. Values are usually very small; high values (basophilia) occur with myeloproliferative neoplasms, chronic myeloid leukaemia and some hypersensitivity states.
