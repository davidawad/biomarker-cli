# Orotic Acid, Urine (`urine-orotic-acid`)

Urinary orotic acid, an intermediate of pyrimidine synthesis. Measured to screen for and differentiate hereditary orotic aciduria and urea cycle or basic amino acid transporter defects that cause hyperammonemia. Expected result: at or below the age-specific upper reference limit; values above it prompt further workup. Excretion is higher in infants and falls with age.
