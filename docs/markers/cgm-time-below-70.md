# CGM time below range (<70 mg/dL) (`cgm-time-below-70`)

Percentage of CGM glucose readings (or hours per day) below 70 mg/dL (3.9 mmol/L). The International Consensus on Time in Range sets maximum targets for people with diabetes; the pregnancy threshold is 63 mg/dL.
