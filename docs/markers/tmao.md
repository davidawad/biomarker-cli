# Trimethylamine N-Oxide (TMAO) (`tmao`)

Gut-microbe-derived metabolite measured in plasma by LC-MS/MS or assay kit; studied as a cardiovascular and kidney risk marker. Expected result for a healthy adult: within the population reference interval below. No single validated clinical cut-off is established; reference intervals differ by sex and by cohort and method.
