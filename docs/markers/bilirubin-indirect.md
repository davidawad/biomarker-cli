# Bilirubin, Indirect (`bilirubin-indirect`)

Indirect (unconjugated) bilirubin, the fraction of bilirubin not conjugated in the liver. Usually calculated as total bilirubin minus direct bilirubin. Expected result in a healthy adult is about 0.10 to 1.00 mg/dL.
