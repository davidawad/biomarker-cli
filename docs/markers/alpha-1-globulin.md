# Alpha-1 Globulin (SPEP) (`alpha-1-globulin`)

Alpha-1 globulin fraction of serum protein electrophoresis (SPEP), reported as g/dL of serum. It contains alpha-1 antitrypsin and other acute-phase proteins, so it rises in inflammation and falls in some liver and protein-losing states. People track it when SPEP is ordered for protein abnormalities or inflammation. Expected result: within the reference interval for the patient's sex (about 0.30-0.50 g/dL combined in the cited adult study).
