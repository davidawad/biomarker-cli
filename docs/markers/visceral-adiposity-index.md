# Visceral Adiposity Index (`visceral-adiposity-index`)

Sex-specific computed index from waist circumference, BMI, triglycerides and HDL cholesterol, intended to express visceral fat function and cardiometabolic risk. A calculated score, not a measured analyte. The cut-offs below are single-study ROC thresholds for metabolic syndrome in one Sicilian primary-care sample, not established clinical thresholds. Expected result: no universal normal value.
