# Cancer Antigen 15-3 (`ca-15-3`)

Cancer antigen 15-3, a mucin-type glycoprotein marker used mainly to monitor metastatic or recurrent breast cancer. It is raised in other cancers and in some benign conditions, so it is not used alone for diagnosis.
