# Squamous Cell Carcinoma Antigen (SCC Ag) (`scc-antigen`)

Squamous cell carcinoma antigen, a serum tumor marker used in squamous cell cancers (notably cervical) for monitoring response and recurrence. Expected result: low in healthy people; the verified sources give a positivity cut-off in cervical cancer but no numeric reference interval for healthy people.
