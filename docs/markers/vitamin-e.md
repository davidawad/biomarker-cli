# Alpha-tocopherol (vitamin E) (`vitamin-e`)

Serum alpha-tocopherol, the main circulating form of vitamin E, an antioxidant that protects cell membranes from lipid peroxidation. Low values indicate deficiency, which is seen mainly with fat malabsorption; because tocopherol travels in lipids, results are often read against serum lipid levels.
