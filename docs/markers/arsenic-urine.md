# Arsenic, Total Urine (`arsenic-urine`)

Total urinary arsenic, all arsenic species combined, including arsenobetaine from seafood. Tracked as a general exposure marker; seafood intake raises it substantially. Expected result in a non-exposed person is low; no outcome-based cut-off was verified.
