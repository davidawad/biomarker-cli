# CGM time above range (>180 mg/dL) (`cgm-time-above-180`)

Percentage of CGM glucose readings (or hours per day) above 180 mg/dL (10.0 mmol/L). Maximum targets from the International Consensus on Time in Range; the pregnancy threshold is 140 mg/dL.
