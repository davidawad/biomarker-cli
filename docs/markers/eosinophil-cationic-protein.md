# Eosinophil Cationic Protein (`eosinophil-cationic-protein`)

Serum concentration of eosinophil cationic protein, a granule protein released by activated eosinophils. Tracked as a marker of eosinophilic airway and allergic inflammation, for example in asthma management. Expected result: below the reference upper limit for the age group; higher values indicate eosinophil activation.
