# Anti-Xa activity (heparin) (`anti-xa`)

Chromogenic anti-factor Xa activity measured on heparin or low-molecular-weight heparin, used to monitor anticoagulant dosing. Levels below the target range suggest under-anticoagulation; levels above it suggest bleeding risk.
