# Neutrophils (Absolute) (`neutrophils-abs`)

Absolute count of circulating neutrophils, the main circulating white cells in bacterial infection defence. Low values (neutropenia) raise infection risk, but are benign in Duffy-null / benign ethnic neutropenia; high values (neutrophilia) occur with bacterial infection, inflammation, stress, smoking, steroids or myeloid disorders.
