# Intrinsic Factor Blocking Antibody (`intrinsic-factor-antibody`)

Serum autoantibody that blocks binding of vitamin B12 to intrinsic factor, measured as a blocking-antibody test. Tracked as a serological marker of autoimmune gastritis and pernicious anemia, usually alongside parietal cell antibodies. Expected result: negative (not detected).
