# Parathyroid Hormone-Related Protein (`pthrp`)

Peptide that mimics PTH action and drives humoral hypercalcaemia of malignancy. Measured mainly to investigate hypercalcaemia with suppressed PTH. Assay methods disagree widely, so the cut-off depends on the method used.
