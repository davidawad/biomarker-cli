# Urine Cotinine (`urine-cotinine`)

Cotinine, the major metabolite of nicotine, measured in urine to objectively verify tobacco or nicotine exposure, for example to check self-reported smoking status. The ranges below are classification cut-offs for smokers versus nonsmokers, not reference intervals. No numeric reference interval for nonsmokers is given here.
