# Free Thyroxine Index (FTI) (`free-thyroxine-index`)

Free thyroxine index (FT4I), a calculated thyroid index from total T4 and T3 resin uptake. Expected result in pregnancy: within the trimester-specific reference interval (5th to 95th percentile in healthy pregnant women); the index is unitless and assay-specific.
