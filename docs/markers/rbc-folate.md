# Red blood cell folate (`rbc-folate`)

Red blood cell (RBC) folate reflects folate status over the roughly 120-day lifespan of the erythrocyte, so it indicates longer-term folate stores rather than recent intake. Low values indicate folate insufficiency, which matters for neural tube defect risk in women of reproductive age.
