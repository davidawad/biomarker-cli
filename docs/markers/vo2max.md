# VO2 Max (`vo2max`)

Maximal oxygen uptake per kilogram of body weight, the standard measure of cardiorespiratory fitness. Higher values are associated with lower all-cause and cardiovascular mortality. Some cut-offs below are published in METs (1 MET = 3.5 mL/kg/min by convention).
