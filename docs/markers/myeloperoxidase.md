# Myeloperoxidase (MPO, inflammatory marker) (`myeloperoxidase`)

Leukocyte-derived heme enzyme measured in serum by immunoassay. Tracked as a marker of neutrophil activation and oxidative inflammation (a separate test from MPO-ANCA autoantibody). Expected result in apparently healthy people: low concentration, below the single-study elevated-risk threshold cited here; no validated clinical reference interval was found.
