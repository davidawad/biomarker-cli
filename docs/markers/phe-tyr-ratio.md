# Phenylalanine/Tyrosine ratio (`phe-tyr-ratio`)

Molar ratio of phenylalanine to tyrosine measured by tandem mass spectrometry, used in newborn screening for phenylketonuria. A raised ratio helps separate true PKU from false-positive hyperphenylalaninaemia, because tyrosine is low in untreated PKU, so the ratio rises.
