# ANCA, Anti-Proteinase 3 (PR3) Antibody (`anca-pr3`)

IgG autoantibody against proteinase 3 (PR3-ANCA), measured by a chemiluminescence immunoassay and reported in vendor chemiluminescence units (CU), which are not interchangeable with U/mL from other assays. Tracked for diagnosis and relapse monitoring in ANCA-associated vasculitis, mainly granulomatosis with polyangiitis. Expected result: negative (below the assay positivity threshold).
