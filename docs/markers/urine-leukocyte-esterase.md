# Urine Leukocyte Esterase (dipstick) (`urine-leukocyte-esterase`)

Dipstick test for leukocyte esterase, an enzyme released by white blood cells. The expected result is negative; a positive result suggests pyuria and is read together with nitrite and urine culture when a urinary tract infection is suspected.
