# Erythrocyte glutathione reductase activation coefficient (EGRAC) (`egrac`)

Functional riboflavin (vitamin B2) status: the ratio of erythrocyte glutathione reductase activity with added FAD to activity without it. Higher values mean lower riboflavin status; cut-offs vary between laboratories and methods.
