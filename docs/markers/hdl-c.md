# HDL Cholesterol (`hdl-c`)

Cholesterol in high-density lipoprotein particles. Adult ATP III categories (low below 40 mg/dL, high at 60 mg/dL or above), sex-specific metabolic-syndrome thresholds, pediatric NHLBI cut-points, non-fasting flag and pregnancy reference intervals.
