# Heart Rate Variability (RMSSD) (`hrv-rmssd`)

Root mean square of successive differences between heartbeats, in ms. A time-domain heart rate variability measure that reflects vagal (parasympathetic) activity. Expected result: no single value; it depends on age, sex and recording method.
