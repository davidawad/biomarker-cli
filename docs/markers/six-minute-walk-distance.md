# Six-Minute Walk Distance (`six-minute-walk-distance`)

Distance walked in six minutes on the standardized six-minute walk test, a measure of functional exercise capacity. Tracked in cardiopulmonary, neuromuscular and cognitive disease. Healthy-adult values depend on age, sex, height and weight (published reference equations, not fixed intervals). No single expected result.
