# Amylase (`amylase`)

Serum amylase is a pancreatic enzyme marker. Reference intervals are sex-specific in adults. Elevated amylase alone is not diagnostic of acute pancreatitis (see the lipase entry for the revised Atlanta criteria, which are relative to the upper reference limit).
