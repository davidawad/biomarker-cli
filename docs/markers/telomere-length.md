# Telomere Length, Leukocyte (`telomere-length`)

Average leukocyte telomere length, measured as a relative T/S ratio (telomere signal divided by a single-copy gene signal, by quantitative PCR). Tracked as a marker of cellular aging. Very short telomeres are associated with telomere biology disorders. The expected result is a value within the age-specific reference range for the assay; the source defines extremely short telomeres as below the first percentile for age.
