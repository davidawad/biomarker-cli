# Platelet Distribution Width (`pdw`)

Platelet distribution width (PDW) is the spread of platelet volumes reported by automated hematology analysers, expressed in femtolitres. It is tracked as a platelet-size (anisocytosis) index alongside MPV and platelet count. Expected result in healthy people: within the analyser-specific reference interval. Values depend on the analyser model and its PDW algorithm, so intervals are not interchangeable between platforms.
