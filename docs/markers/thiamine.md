# Vitamin B1 (thiamine diphosphate, whole blood) (`thiamine`)

Thiamine diphosphate (ThDP, the active form of vitamin B1) measured in whole blood, the main circulating thiamine form. Low values indicate low thiamine status, which can cause beriberi and Wernicke-Korsakoff syndrome; there is no universally accepted deficiency cutoff.
