# sTfR/log Ferritin Index (`stfr-logferritin-index`)

Ratio of soluble transferrin receptor to log ferritin (unitless index) used to assess iron status. Expected result for a healthy child or adolescent: at or below the age- and sex-specific cut-off; values above the cut-off indicate iron deficiency without anemia in the cited study.
