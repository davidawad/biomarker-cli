# Creatinine Clearance (`creatinine-clearance`)

Clearance of creatinine from the blood, in mL/min, used as an estimate of glomerular filtration rate. Measured from a timed (24-hour) urine collection with a paired serum creatinine, or predicted with the Cockcroft-Gault equation. Expected result for a healthy adult: about 66 to 151 mL/min depending on the creatinine method and sex (see ranges). Creatinine clearance is method-dependent; compare results only with the same method.
