# Sweat Chloride (`sweat-chloride`)

Chloride concentration measured in sweat collected by pilocarpine iontophoresis; the reference test for CFTR dysfunction and the main laboratory step in diagnosing cystic fibrosis. Values are interpreted against consensus decision limits, not a population reference interval.
