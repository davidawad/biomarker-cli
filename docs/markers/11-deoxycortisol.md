# 11-Deoxycortisol (`11-deoxycortisol`)

Serum 11-deoxycortisol, the cortisol precursor, measured by LC-MS/MS. Reference intervals apply to morning (6-8 AM) samples only; values are higher in the morning than in the evening. Expected result in healthy adults: within the reference interval.
