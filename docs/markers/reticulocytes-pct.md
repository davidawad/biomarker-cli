# Reticulocytes (%) (`reticulocytes-pct`)

Percentage of circulating red cells that are reticulocytes, the young RNA-containing red cells released from the marrow, as counted by automated analysers. Low values suggest reduced marrow output (aplasia, nutrient deficiency, CKD); high values indicate increased erythropoiesis, as after blood loss or haemolysis.
