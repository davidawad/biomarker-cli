# HE4 (Human Epididymis Protein 4) (`he4`)

Human epididymis protein 4, a serum glycoprotein measured by immunoassay. Used with CA125 and the ROMA index in evaluating ovarian tumours and monitoring ovarian cancer. Expected result in healthy women: at or below the reference upper limit, which is higher after menopause.
