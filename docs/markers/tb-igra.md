# TB Interferon-gamma Release Assay (QuantiFERON) (`tb-igra`)

Whole-blood interferon-gamma release assay (QuantiFERON-TB Gold Plus) for Mycobacterium tuberculosis infection. Interferon-gamma is measured after stimulation with TB antigens (TB1, TB2) minus the nil control, in IU/mL. Reported as positive, negative, borderline or indeterminate. Expected result: negative (TB1 and TB2 below the 0.35 IU/mL cut-off).
