# Controlled Attenuation Parameter (FibroScan CAP) (`fibroscan-cap`)

Ultrasound-based estimate of hepatic steatosis (fat in the liver) from FibroScan, reported in dB/m and graded S0 to S3. Used to screen for and grade liver fat without biopsy. Expected result in a person without steatosis is below 248 dB/m.
