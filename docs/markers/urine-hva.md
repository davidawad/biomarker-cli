# Homovanillic Acid (HVA), Urine (`urine-hva`)

Dopamine metabolite excreted in urine, used with VMA as a biochemical screen for neuroblastoma and other catecholamine-secreting tumours in children. Pediatric values fall with age and are normalised to creatinine in the ranges below, so ranges are age-specific. Expected result for a healthy child: below the age-specific upper limit.
