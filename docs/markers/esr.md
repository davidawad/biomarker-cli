# Erythrocyte sedimentation rate (ESR) (`esr`)

Rate at which red cells settle in an anticoagulated tube over one hour (Westergren method), a non-specific marker of acute-phase response and chronic inflammation. Raised values reflect inflammation, infection, malignancy or high fibrinogen/immunoglobulin levels; it rises with age, is higher in women, and is raised in pregnancy.
