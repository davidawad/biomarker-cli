# Red cell distribution width, standard deviation (`rdw-sd`)

Standard deviation of the red cell volume distribution, reported in femtolitres by Sysmex-type analysers. It measures red cell size variation (anisocytosis) and is reported alongside the coefficient-of-variation form of RDW (RDW-CV).
