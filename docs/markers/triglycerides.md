# Triglycerides (`triglycerides`)

Triglyceride concentration, interpreted by ATP III categories, the fasting/non-fasting distinction, pediatric NHLBI age bands, the 2018 AHA/ACC non-fasting risk enhancer, and pregnancy reference intervals. Life-threatening concentrations are flagged for pancreatitis risk.
