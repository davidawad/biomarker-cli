# Urine Hyaline Casts (`urine-hyaline-casts`)

Hyaline casts (Tamm-Horsfall protein cylinders) counted in urine sediment. Casts can occur in normal subjects and in many renal and non-renal conditions, so the count is read with the clinical context. Expected result: none or very few casts per specimen; the only verified numeric upper limit found is for newborns and infants, from bright-field microscopy and an automated analyser.
