# Haptoglobin (`haptoglobin`)

Plasma glycoprotein that binds free haemoglobin released from red-cell destruction and clears it via CD163 macrophages. Low values indicate ongoing intravascular or extravascular haemolysis (or reduced hepatic synthesis); it is an acute-phase protein, so it can rise with inflammation.
