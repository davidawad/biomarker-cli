# Chlamydia trachomatis NAAT (`chlamydia-naat`)

Nucleic acid amplification test (NAAT) that detects Chlamydia trachomatis DNA or RNA in urine, vaginal, cervical, rectal, pharyngeal or urethral specimens. It is the standard screening and diagnostic test for chlamydial infection and is tracked for sexually transmitted infection screening. Expected result: negative (Chlamydia trachomatis not detected).
