# Galectin-3 (`galectin-3`)

Beta-galactoside-binding lectin released by activated macrophages; measured as a marker of myocardial fibrosis and remodelling and as a prognostic marker in heart failure. Expected result in healthy adults: below the upper reference limit. Limits differ by assay and by age, so use the range that matches the assay and age.
